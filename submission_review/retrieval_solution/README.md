# Поиск объявлений по запросам

Проект строит текстовые индексы объявлений, подбирает кандидатов и ранжирует их моделью LightGBM. Готовый результат находится в `answer.csv`: для каждого `query_id` записаны идентификаторы до 50 объявлений в порядке убывания оценки. Формат файла — UTF-8, колонки `query_id,answer`.

## Содержимое

- `prepare.py` выбирает обучающие запросы, собирает историю кликов и корпус объявлений. Первые 3000 запросов используются при обучении с добавлением известных положительных примеров; следующие 700 входят в итоговое обучение без такого добавления. Ещё 800 запросов сохраняются в корпусе для совместимости с уже обученной моделью, но их признаки не вычисляются.
- `build_index.py` создаёт разреженные текстовые индексы.
- `retrieval.py` объединяет глобальную и локальную текстовую выдачу, оставляет до 1000 кандидатов и считает признаки пары «запрос — объявление». Более широкий глобальный поиск помогает находить объявления из других городов.
- `generate_features.py` сохраняет признаки для обучения блоками по 100 запросов.
- `train_ranker.py` обучает модель с зафиксированными параметрами. Подбор параметров и отдельные этапы оценки в этой версии удалены.
- `predict.py` применяет `ranker.txt` к запросам бенчмарка и записывает `answer.csv`.
- `run.py` запускает необходимые этапы, `package_solution.py` собирает архив.
- `common.py` содержит обработку русского текста и выбор лучших результатов.

Файл `model_config.json` хранит порядок признаков модели. `requirements.txt` фиксирует версии библиотек.

Расширенный поиск улучшил локальный Recall@50 на отложенных запросах: с 0,8895 до 0,8920 на выборке из 700 запросов и с 0,9029 до 0,9110 на выборке из 800 запросов. Эти значения рассчитаны по наблюдаемым положительным парам и не являются оценкой скрытого бенчмарка.

## Запуск

Нужен Python 3.14 и зависимости из `requirements.txt`. Исходные файлы `train.parquet`, `benchmark_queries.parquet` и `benchmark_items.parquet` должны находиться в папке `data`. Их можно передать архивом, в котором эти файлы лежат в корне:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py --archive "C:\путь\к\данным.zip" --use-model
```
